Atualmente, estou em transição de carreira da área da Educação para o desenvolvimento de software, e este espaço reflete minha evolução no ecossistema de tecnologia, aplicando boas práticas de front-end e design responsivo.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout (Flexbox/Grid) e responsividade.

- **Figma/Canva:** Planejamento de interface e design visual.
